# 🍞 こもれびベーカリー（Komorebi Bakery）
このサイトは、架空のベーカリー「こもれびベーカリー」の  
**店舗紹介・こだわり・メニューをシンプルにまとめた Web サイト**です。

PC・スマホどちらでも見やすいように  
**レスポンシブデザインを意識して制作**しました。

---

## 🚀 主なページ構成
### ■ トップページ（Hero）
- 店名・キャッチコピーを中央に配置
- ベーカリーの雰囲気が伝わるメイン画像
- 「メニューを見る」ボタンでメニューへ誘導

### ■ こだわり（About）
- ベーカリーの想い・素材へのこだわり
- 画像＋テキストの横並びレイアウト
- スマホでは縦並びに切り替わるレスポンシブ対応

### ■ メニュー（Menu）
- カード型デザインでパンを一覧表示
- 画像 → 商品名 → 説明文 の縦並び
- スマホでは 1 カラム表示
- 商品名が自然に収まるように幅・文字サイズを調整

### ■ 店舗案内（Access）
- 外観画像
- 住所・営業時間・電話番号
- シンプルで見やすい構成

## 💡 工夫したポイント
### ■ スマホ最適化（レスポンシブ対応）
- 画像とテキストの縦並び切り替え
- メニューは 1 カラム表示
- 文字サイズ・余白を調整して読みやすく

### ■ カード型メニューのデザイン
- パン画像を大きく見せる
- 商品名が折り返されないように調整
- 影・角丸で柔らかい印象に

### ■ 全体の世界観を統一
- ベージュ系の背景色
- やさしい雰囲気のフォント
- こもれびベーカリーらしい温かいデザイン

### ■ フォルダ構成をシンプルに
- HTML / CSS / 画像のみの軽量構成
- 初心者でも読みやすいコードに整理

## 📦 セットアップ方法
ローカルで開く場合：

```bash
# リポジトリを clone
git clone https://github.com/Mosh9816/bakery-website.git

# ディレクトリへ移動
cd bakery-website

# index.html をブラウザで開く
open index.html   # Mac
start index.html  # Windows
```
